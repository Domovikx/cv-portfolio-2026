Собери и задеплой CV на GitHub Pages.

1. Убедись, что нет незакоммиченных изменений (`git status`).
2. Выполни `npm run deploy` (build + gh-pages на ветку gh-pages).
3. Сообщи итоговую ссылку: https://domovikx.github.io/cv-portfolio-2026/

Не коммить ничего дополнительно без запроса пользователя.

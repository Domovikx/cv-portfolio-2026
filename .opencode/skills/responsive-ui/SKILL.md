# Responsive UI (адаптивность CV-портфолио)

## Подход: DESKTOP-FIRST

Базовые стили пишем под десктоп, мобильные ширины переопределяются через
`@media (max-width: ...)`. Так сложилось исторически (проект рос сверху вниз).
При добавлении новых блоков: сначала десктоп, затем `max-width`-брейкпоинты.
Переход на mobile-first возможен, но это отдельный рефактор — не делать
«за компанию».

## Канон-брейкпоинты проекта

| Ширина  | Что происходит                                                                                                                                                                                             |
| ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| > 992px | Десктоп: hero две колонки (текст + портрет), about 4 колонки, projects 2 колонки                                                                                                                           |
| ≤ 992px | Hero в одну колонку (портрет по центру под текстом), about 2 колонки, projects 1 колонка                                                                                                                   |
| ≤ 860px | Навигация шапки скрывается (остаются логотип, переключатель языков, CTA)                                                                                                                                   |
| ≤ 768px | Контейнер padding 16px; секции padding 48px; заголовки секций 24px; hero-заголовок 34px; **кнопки hero складываются в колонку на всю ширину**; длительность озвучки скрывается; модалка: заголовок 24→20px |
| ≤ 640px | Кнопка озвучки — только иконка (текст скрыт, `aria-label` сохраняется)                                                                                                                                     |
| ≤ 600px | about/projects/education сетки → 1 колонка                                                                                                                                                                 |
| ≤ 480px | Шапка: текст логотипа скрыт (остаётся «И»), высота 60px; модалка padding 24/16px, `max-height: calc(100dvh - 24px)`                                                                                        |

## Правила

1. **Проверяй после любых UI-правок**: 375 / 480 / 640 / 768 / 992 / 1280px
   (DevTools → device toolbar). Регресс адаптивки — баг.
2. Кнопки/экшены: на мобиле либо стек в колонку на всю ширину (hero), либо
   компактный ряд с переносом. Никаких фиксированных ширин.
3. Текстовые элементы: без `white-space: nowrap` в инлайн-кнопках, если текст
   может не влезть — перенос или скрытие части (как кнопка озвучки).
4. Модалки: `max-height: calc(100dvh - ...)` + внутренний `.scroll` (скроллбар
   не должен ломать радиус 24px). Заголовок модалки всегда на месте.
5. Тач-таргеты ≥ 44px; `aria-label` сохраняется при визуальном скрытии текста.
6. Сетки: базово `repeat(auto-fit, minmax(...))` или явные брейкпоинты —
   но всегда есть состояние 1 колонки ≤ 600px.
7. При добавлении нового виджета — пропиши его брейкпоинты в этой памятке.

## Быстрая проверка

```bash
npm run dev   # http://localhost:5173/cv-portfolio-2026/
# DevTools → toggle device toolbar → 375/480/640/768/992/1280
```
